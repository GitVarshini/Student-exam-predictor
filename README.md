# Student Exam Performance Predictor

Predicting students’ exam scores using machine learning on real-world data.

---

## Project Overview

This project demonstrates a simple yet effective machine learning model that predicts students’ exam performance based on attributes like gender, ethnicity, parental education, and test preparation course.  
It’s built with Python and uses the popular Scikit-learn library.

---

## Dataset

The data is from the [Students Performance in Exams](https://www.kaggle.com/datasets/spscientist/students-performance-in-exams) dataset on Kaggle.  
It includes student demographic details and scores in math, reading, and writing.

---

## Features

- Data loading and preprocessing
- Exploratory data analysis (basic statistics and visualization)
- Predicting exam scores using Linear Regression
- Evaluation of the model with Mean Squared Error and R² score

---

## How to Use

1. Download or clone this repository.
2. Open the Jupyter notebook (`.ipynb`) file in Google Colab or Jupyter Notebook.
3. Run the notebook cells step-by-step to see how the model is built and evaluated.
4. Feel free to modify and improve the model!
